Product Management System
Project Overview
The Product Management System is a web-based application developed using Python and Django. It allows users to manage product information efficiently through CRUD (Create, Read, Update, Delete) operations.
Technologies Used
•	Python
•	Django
•	HTML
•	CSS
•	Bootstrap
•	SQLite 
Features
•	Add new products
•	View product details
•	Update existing product information
•	Delete products
•	Manage product records through a user-friendly interface
Project Structure
•	manage.py – Django project management file
•	templates/ – HTML templates
•	static/ – CSS, JavaScript and other static files
•	requirements.txt – Project dependencies
Installation and Setup
1.	Clone the repository:
git clone https://github.com/ashleshakatore/Product_management_system.git
2.	Navigate to the project directory:
cd product_ms_project
3.	Create a virtual environment:
python -m venv env
4.	Activate the virtual environment:
Windows:
env\Scripts\activate
5.	Install dependencies:
pip install -r requirements.txt
6.	Apply migrations:
python manage.py migrate
7.	Run the development server:
python manage.py runserver
8.	Open your browser and visit:
http://127.0.0.1:8000/
